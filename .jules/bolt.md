## 2024-05-24 - Framebuffer Fallback Color Conversion Performance
**Learning:** In `pwnagotchi/ui/hw/libs/fb/fb.py`, when `numpy` is absent, the pure Python `_888_to_565` fallback function becomes a major performance bottleneck for UI rendering because it relies on byte string concatenation (`b += ...`) and `int.to_bytes` inside a tight loop across thousands of pixels. This causes O(N^2) memory reallocation overhead.
**Action:** When performing bulk binary data construction in Python inside loops (especially for hardware rendering or pixel manipulation), always pre-allocate a `bytearray` to the required size and use direct index assignment combined with simple bitwise arithmetic (e.g., `val & 0xFF`, `val >> 8`) instead of `int.to_bytes` or structural packing. This approach provides over a 10x performance improvement in pure Python.
